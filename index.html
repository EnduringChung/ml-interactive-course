ML, Statistics & LLM — Interactive Course

An interactive course on machine learning, statistics, and large language models, with a running theme of biological data analysis. Every code cell on this site runs directly in your browser — no installation, no server, no account. It works especially well in Safari on iPad.

How to use this site

  1. Open a page (start with 0.1 Python for Numerical Work).
  2. Read the Basic Concept section and run the worked example by pressing Run Code on the cell.
  3. Edit the cell — change a number, swap a dataset — and run it again. This is where learning happens.
  4. Answer the Concept Questions from memory, then do the Drills.
  5. Work through Exercises, Advanced Questions, and Complex Questions. Hints and full solutions are inside collapsible blocks — try the problem before opening them.

Your edits stay on your device; refresh the page to return to the original code.

Parts 0–1 cover the toolkit (Python, NumPy, pandas, EDA, splitting; statistics bridge). Parts 2–5 build, fit, honestly evaluate, and regularize the classical model zoo; Parts 6–9 add nonlinear smoothers, tree ensembles, SVMs, and the unsupervised toolkit. Later parts layer in deep learning (T3), survival analysis, multiple testing, and LLMs.

The three execution tiers

Tier What it means Where it runs
T1 — Live Cells are fully editable and runnable in-browser (Pyodide / webR) Right here, on this site
T2 — Frozen output Real code with pre-computed outputs, plus a downloadable script Read here; run locally
T3 — Colab/local Lesson text + live concept cells, heavy compute via a Colab badge Google Colab or your machine

Parts 0–1 below are fully Tier 1. Later parts layer in T2 (Bioconductor differential expression) and T3 (PyTorch, single-cell, local LLMs).

What’s inside each page

Every subtopic page follows the same seven-section template, so your study loop is always identical:

  1. Basic Concept — plain language + one worked example
  2. Concept Questions — check the concept landed
  3. Drills & Exercises — rebuild reflexes, then solve fuller problems
  4. Advanced Information & Pitfalls — edge cases, and a flawed AI snippet to fix
  5. Advanced Questions — with hints and solutions
  6. Complex Questions — deliberately cross topic boundaries
  7. Summary — takeaways and what comes next
