10.3 Multilayer Neural Networks

A hidden layer turns fixed features into learned features: \(\hat y = W_2\,g(W_1 x + b_1) + b_2\). Where 6.3 hand-designed bases (polynomials, splines) and 9.2 extracted unsupervised directions, the MLP tunes its basis to the supervised task. This page trains one for real — in the browser — via scikit-learn’s live MLPClassifier.

Tier 3 — the PyTorch lab runs in Colab; the concept labs below run right here (scikit-learn is wasm-available):

1. Basic Concept

For input \(x \in \mathbb{R}^d\), a one-hidden-layer network is

\[h = g(W_1 x + b_1) \in \mathbb{R}^{h_1}, \qquad \hat y = W_2 h + b_2\]

  • Each hidden unit is a neuron (10.2); the layer applies \(h_1\) of them in parallel — a matrix multiply plus a scalar nonlinearity.
  • \(\hat y\) is linear in \(h\): the network is a linear model on learned features. All nonlinearity lives in \(g\) — remove it and \(W_2 W_1\) collapses into a single linear map (Exercise: verify).
  • Universal approximation: one sufficiently wide hidden layer with a sigmoid/tanh/ReLU nonlinearity can approximate any continuous function on a compact set arbitrarily well. It says nothing about width needed, optimization, or generalization — those are the real constraints.

Worked example — the same two-moons that defeated the single neuron, with an MLP trained live (scikit-learn, runs in your browser):

The MLP bends the boundary along the moons because its hidden units learn moon-shaped features. Test this honestly (4.2): hold data out before believing.

2. Concept Questions

  1. Delete the activation: \(h = W_1 x + b_1\), \(\hat y = W_2 h + b_2\). Exactly what function class can the resulting network express, and why does depth add nothing?
  2. Universal approximation says one wide layer suffices. Name the two practical currencies it ignores, and which one 7.4 random forests also ignores.
  3. The output layer above is linear-in-\(h\) and fed to logistic loss. Where do softmax and sigmoids live in a K-class net, and why is the hidden nonlinearity not optional while the output squashing is (for regression)?
  4. A network has 2 → 100 → 100 → 1 units. Count parameters exactly (weights + biases).
  5. MLPClassifier standardizes nothing for you. What breaks if you feed raw features with scales 1 and 10⁴ — and which earlier page’s advice applies verbatim?
Answers
  1. \(\hat y = W_2(W_1 x + b_1) + b_2 = (W_2 W_1)x + (W_2 b_1 + b_2)\) — a single affine map. Any stack of linear layers factors into one linear layer; representation learning is the nonlinearity.
  2. Data (how many samples to pin down the approximation) and optimization (whether SGD can find it) — generalization’s sample complexity. Random forests ignore both too: consistency results assume the forest grows well past the data’s support. The MAP is universal approximation is an existence theorem: “a good net exists” ≠ “SGD finds it from n samples.”
  3. K-class: output layer = K logits (linear in \(h\)), softmax applied in the loss (CE), sigmoids nowhere. Regression: identity output — squashing would bound the response range artificially. Hidden nonlinearities are the model’s expressive core; output activations are interface choices.
  4. \(2{\cdot}100 + 100 + 100{\cdot}100 + 100 + 100{\cdot}1 + 1 = 200 + 100 + 10{,}000 + 100 + 100 + 1 = 10{,}501\).
  5. Ill-conditioned optimization (GD crawls along flat/steep directions) and saturation of tanh/sigmoid units; identical to 3.3/10.2’s advice — standardize inside a pipeline fitted on training folds only (4.3).

Drills

Exercises (with solutions)

Exercise 1. Write a count_params(sizes) function for an arbitrary architecture [d, h1, ..., hk, out] and verify it against scikit-learn: build MLPClassifier(hidden_layer_sizes=(16, 16)), sum sum(c.size for c in clf.coefs_) + sum(b.size for b in clf.intercepts_), and match your formula. Which layer dominates as widths grow?

Solution

\[P = \sum_{\ell=1}^{k+1} (s_{\ell-1} \cdot s_\ell + s_\ell)\]

(For binary classification scikit-learn uses a single sigmoid output unit — set the last size to 1 to match it; K-class nets have K output logits.)

The \(s_{\ell} \cdot s_{\ell+1}\) weight blocks dominate quadratically in width — doubling width quadruples cost. Depth adds parameters linearly in the layer sizes but compounds expressiveness (Q1); width is where the money goes.

Exercise 2. Random features vs learned features: fit (a) ridge on the raw 2 features, (b) ridge on 100 fixed random tanh features \(h = \tanh(XW_1 + b_1)\), and (c) scikit-learn’s trained MLP, on two-moons with n = 100. Rank the three test accuracies over 20 repetitions. What does (b) vs (c) isolate?

Solution
Random nonlinear features already beat raw ridge (nonlinearity for free — the kernel/random-features view of 6.3); training the features beats random ones — that gap is exactly what “representation learning” buys. It also costs optimization and variance at small n: watch the MLP’s higher spread.

Exercise 3. Dying ReLUs, measured: build a 2 → 64 → 64 → 2 scikit-learn net (relu) on moons, then for hidden layers’ inputs compute the fraction of (point × unit) pre-activations that are negative (dead on that point). Compare against activation="tanh". Now flip to He-style thinking: why does ReLU tolerate (and even prefer) ~half the units being “off” per point, and when does “half off” become “all dead”?

Solution
ReLU switching off ~half its units per point is sparsity, not death — the active set still carries gradients, and different points use different units (that’s the piecewise-linear magic). Death is population-level: a unit whose pre-activation is negative for every training point gets exactly-zero gradient forever. Big negative biases, too-large learning rates that knock units off the data manifold, or unscaled inputs drive units to that absorbing state; once dead, only reinit or lucky regularization revives them.

4. Advanced Information & Pitfalls

  • Zero init poisons hidden layers: all units in a layer receive identical gradients and stay identical forever. Use random init scaled by fan-in: Xavier for tanh/sigmoid (\(\text{Var} \propto 1/\text{fan}_{in}\)), He for ReLU (double it — half the units output zero).
  • More layers ≠ better: depth compounds optimization difficulty and variance on small data; scikit-learn’s MLP with two modest hidden layers beats a naive 10-layer stack on tabular problems. (The remedy at scale is normalization + residuals — 10.9’ block.)
  • Softmax belongs in the loss: applying it to logits and using CrossEntropyLoss (which applies it again) is a classic silent bug — the model trains but never confident, gradients squashed by double squashing.
  • Undertraining is silent: MLPClassifier stops at max_iter (default 200) with only a warning; check clf.n_iter_ against max_iter — “I asked for 2000, it stopped at 200” is the most common “neural nets don’t work here” misdiagnosis.
  • The MLP interpolates noise at zero training error: train accuracy 1.0 on noisy moons says nothing — the 4.2 split is not optional decoration.
  • Input scaling inside CV: StandardScaler fitted on the full dataset leaks (mildly) — fit it per training fold (4.3).

5. Advanced Questions

Q1. Width vs depth, an experiment: on two-moons (n = 400, 20% test), compare test accuracy for architectures with matched parameter budgets — one wide layer (e.g., 100 units ≈ 402 params) vs two narrower (30, 30 ≈ 1,022) vs three (20, 20, 20 ≈ 921) — at the same training-set size. Then repeat at n = 4000. Compose the results into a claim about when depth pays, and connect to the bias–variance framing of 4.4.

Hint Fix the parameter count first, then let data size arbitrate: depth wins where compositional structure exists and n is sufficient; at small n the extra layers are variance.
Solution
Typical outcome: at n = 400 the architectures are within noise of each other (the problem is two-dimensional — its structure is cheap either way; variance dominates); at n = 4000 the deeper stacks edge ahead on the curved boundary. Honest claim: depth pays when the target function is compositional and n supports the extra parameters — on 2-D toy data the effect is small, which is itself the lesson: universal approximation is about existence, and data decides whether architecture matters. On truly compositional problems (images: 10.6; sequences: 10.7), depth with the right structure (weight sharing) is not optional.

Q2. PCA as a linear autoencoder: fit PCA(n_components=1) on standardized moons and fit an autoencoder-shaped net — MLPRegressor with hidden sizes (2, 1, 2), identity output, MSE on X→X. Project both onto their 1-D representations and reconstruct. Show the two reconstructions are related by an invertible linear map (up to optimization error) — i.e., a linear hidden activation makes the MLP’s bottleneck exactly PCA’s subspace. What does this imply about what nonlinear activations add to compression?

Hint Both methods find the top-variance 1-D subspace when the encoder is linear; compare reconstructions after optimal rotation/scaling.
Solution
With identity activations, the (2→1→2) net’s encoder is \(v^\top x\) for some vector \(v\) and MSE reconstruction is minimized exactly when \(v\) spans the first principal direction — linear autoencoder ≡ PCA (Bourlard–Kamp / Baldi–Hornik). Nonlinear activations buy curved manifolds: the same architecture with tanh can follow the moon’s arc, which no linear projection contains. That’s the whole value proposition of deep representation learning: PCA’s subspace → nonlinear manifold, with autoencoders and t-SNE/UMAP as the unsupervised cousins (the T3 extension of Part 9).

6. Complex Questions

C1 (× 7.5 gradient boosting × 4.3 CV). Both MLPs and boosted trees fit residuals of an additive model — one in function space via hidden features, one in tree space via stagewise fitting. On moons and on a 10-feature mixed-scale tabular simulation, run MLPClassifier vs HistGradientBoostingClassifier under a shared CV protocol with tuned capacity (width/depth vs iterations/depth). Which model wins where, and does the ranking survive when you add 5 pure-noise features? (This previews 10.10’s decision rule.)

C2 (× 9.2 PCA × 5.2 ridge). Preprocessing an MLP’s inputs: on a dataset with strongly correlated features (build one: \(x_2 = x_1 + \text{noise}\), etc.), compare (a) raw input, (b) PCA-whitened input, (c) ridge-penalized MLP, on test accuracy and on the conditioning of the first-layer gradient (approximate: fit each and compare n_iter_ to convergence at fixed lr). Connect: whitening decorrelates gradients exactly as ridge tames variance — and both are partial answers to the same ill-conditioning.

7. Summary

  • MLP = linear model on learned nonlinear features; remove the activation and depth collapses to one affine map.
  • Hidden layers are trainable basis functions — the supervised generalization of 6.3 and the nonlinear descendant of 9.2.
  • Universal approximation is an existence theorem; data and optimization decide what’s practical.
  • Parameter count is quadratic in width; init scaling (Xavier/He) and input standardization are optimization hygiene, not superstition.
  • scikit-learn’s MLP is enough to feel all of this live; the same net in PyTorch exposes the training loop explicitly.
