10.2 Single-Layer Neural Networks

One neuron — an affine map followed by a nonlinearity — is the atom every later page composes. Choose the pieces carefully and the single neuron is your old friends: sigmoid + log-loss is logistic regression (3.3); identity + squared error is linear regression (2.2). Deep learning begins when you stop hand-picking features and start stacking these atoms.

Tier 3 — the PyTorch lab runs in Colab; every concept below is demonstrated in live NumPy cells:

1. Basic Concept

A single neuron computes, for input \(x \in \mathbb{R}^d\):

\[z = w^\top x + b, \qquad a = g(z)\]

with \(g\) the activation. The pairing of \(g\) with a loss is not arbitrary:

task activation \(g\) loss identity
binary classification sigmoid binary cross-entropy logistic regression
regression identity MSE linear regression
multiclass (one-vs-rest crude) sigmoid each BCE each K logistic regressions

Training by gradient descent (10.4 develops the machinery): for BCE with sigmoid, the derivatives collapse beautifully to \(\nabla_w = X^\top(\hat y - y)/n\) — the same residual form as linear regression (2.2).

The boundary is a single line — one neuron cannot bend. Stacking neurons is 10.3’s whole point.

2. Concept Questions

  1. In what precise sense is a sigmoid neuron with BCE loss the same model as logistic regression from 3.3? What differs (if anything) in how each course page fits it?
  2. Why does the gradient \(\nabla_w = \tfrac{1}{n}X^\top(\hat y - y)\) have no factor that looks like the sigmoid derivative \(p(1-p)\) — where did it go?
  3. The worked example standardizes \(X\) first. Which two pathologies does unscaled input cause for (a) gradient descent, (b) the sigmoid itself?
  4. A neuron’s output is 0.9999 on a negative example. What is its BCE contribution and its gradient component — and what is this regime called?
  5. K sigmoid neurons on the same input with independent targets: how many models is that, and what would you change to make them share what they learn?
Answers
  1. Same parameterization (\(w^\top x + b\) through a sigmoid), same likelihood, same MLE problem. Only the fitter differs: 3.3 used Newton/IRLS (statsmodels); here, plain first-order gradient descent. Same optimum for convex loss; different path to it.
  2. The sigmoid derivative cancelled: BCE’s ∂/∂z contributes \(p - y\) and sigmoid’s ∂a/∂z contributes \(p(1-p)\); the chain rule cancels the \(p(1-p)\) exactly (do it once by hand — it’s the reason sigmoid+BCE is the “matched pair”). Unmatched pairs (sigmoid + MSE) don’t cancel → slow, plateau-prone learning.
    1. GD is isotropic: features on scales 1 and 1000 force a tiny learning rate that crawls along the flat direction (the ridge pathology of 5.2 in dynamics form). (b) \(z = w^\top x\) large in magnitude saturates the sigmoid → gradients ≈ 0 at initialization.
  4. Loss \(-\log(1 - 0.9999) \approx 9.2\) (vs 0.69 at chance) and gradient ≈ (0.9999 − 0)·x: a strong, correctly-signed push — saturation is only a problem when the model is confidently wrong in a way it can’t escape (here it can). The dangerous saturation is confidently wrong with tiny gradients — MSE + sigmoid.
  5. K independent logistic regressions (one-vs-rest). Sharing starts when neurons feed common downstream structure — hidden layers (10.3) — or when outputs share a body via multitask heads.

3. Drills & Exercises

Drills

Predict, then run.

Exercises (with solutions)

Exercise 1. Train the single sigmoid neuron on two-moons as in Section 1, then fit sklearn’s LogisticRegression on the same standardized data. Compare accuracy and the coefficient vectors. How close is 300 steps of plain GD to the Newton-solver optimum — and what would shrink the gap (without changing models)?

Solution
Identical model, near-identical coefficients — the loss is convex, so any sane optimizer lands in the same basin; only convergence speed differs. Shrinking the gap: more steps, feature scaling (done), or a smarter first-order method (momentum/Adam, 10.4); or the second-order route statsmodels took. For a convex problem the “optimizer wars” are about iteration cost only.

Exercise 2. A neuron can only cut with a hyperplane — prove it to yourself constructively: for the four XOR points, show that no choice of \((w, b)\) achieves 4/4 accuracy by (a) arguing geometrically in two sentences, and (b) brute-force checking a grid of \((w_1, w_2, b)\). Then show one hidden layer of two sigmoid neurons fixes it (forward pass only — hand-pick the weights).

Solution
  1. XOR’s positive points are diagonal corners: any half-plane containing both also contains a negative corner, because the positive set is not linearly separable (its convex hull intersects the negatives’).
The grid confirms 3/4 is the ceiling; the hand-set hidden layer computes AND and an OR-like unit, and the output neuron implements “OR but not AND” — a composition of two cuts. Two neurons bought non-convexity: this is the entire plot of 10.3.

4. Advanced Information & Pitfalls

  • The activation–loss pairing is load-bearing: sigmoid+BCE (and softmax+CE) cancel their Jacobians into the clean residual form; sigmoid+MSE multiplies every gradient by \(p(1-p)\) — vanishing exactly when the neuron is confident. If you write a custom head, keep the matched pairs.
  • Class imbalance moves the threshold, not the model: a 1:100 problem still trains fine; accuracy and the 0.5 cutoff become meaningless (see 3.1.5 AUPRC). The neuron doesn’t know it should prefer precision or recall — you choose the operating point.
  • Initialization matters even here: \(w = 0\) is a valid start for a convex single neuron (symmetry can’t trap you with no hidden layers), but with hidden layers zero init is fatal — all neurons receive identical gradients (10.3).
  • Full-batch GD on 200 points is fine; streaming is not free: mini-batching adds gradient noise whose scale interacts with the learning rate — the first place to look when a torch run “explodes” (10.4).
  • predict_proba is a calibration claim: a sigmoid outputs a probability only under correct specification; miscalibration is the norm under imbalance or regularization (check reliability before quoting probabilities clinically).

Read & Refactor AI Code

This AI-generated single-neuron trainer has three bugs. Diagnose, then compare with the fix.

What’s wrong, and the fix
  1. Huge random init + raw scales: \(z\) lands at \(\pm\) hundreds → saturated sigmoid → gradients of either sign barely move the loss; and unstandardized features give an ill-conditioned problem. Fix: small (or zero) init, standardize inputs.
  2. Wrong sigmoid sign: 1/(1+exp(z)) computes σ(−z) — the model’s outputs (and hence the loss surface) are mirrored; combined with bug 3 the dynamics are nonsense. Fix: 1/(1+exp(-z)).
  3. Wrong residual: the BCE gradient is \(X^\top(p - y)/n\), not \(X^\top(p + y)/n\). The AI “hallucinated” a plus — the kind of error gradient-checking catches in one line (10.4 Exercise 2).

5. Advanced Questions

Q1. The single-neuron BCE loss is convex in \((w, b)\) — prove it by composing known facts (affine ∘ log-concave sigmoid ∘ convex log-loss), then answer: since a convex function has no bad local minima, why do people still observe “stuck” runs with a single neuron? Construct the stuck case numerically with a poorly scaled feature and a large learning rate (divergence and plateau both count).

Hint Convexity rules out local traps, not divergence, plateaus of ill-conditioning, or numerical saturation. Plot the loss for lr ∈ {0.01, 1, 100} on raw (unscaled) moons.
Solution

\(z = w^\top x + b\) is affine in \((w,b)\); \(L(z) = -[y\log\sigma(z) + (1-y)\log(1-\sigma(z))]\) is convex in \(z\) (each term: −log of a log-concave function composed affinely); affine ∘ convex is convex; sums of convex are convex. QED — no local minima, but: divergence (lr too large overshoots along the steep direction; loss oscillates upward), plateaus (ill-conditioned curvature: progress along the flat direction is glacial even though the direction is “correct”), saturation (logits far from 0 make float arithmetic lose the gradient before the math does). Live:

Convexity is about the destination, not the speed — optimization difficulty survived into deep learning as conditioning, not as local minima.

Q2. Sigmoid outputs claim probabilities. On the imbalanced two-moons variant (flip 90% of class-1 labels to 0, so prevalence ≈ 5%), train the single neuron, draw its reliability table (predicted-probability quintiles vs observed frequency), then fit Platt scaling — one more sigmoid mapping logit → label, by MLE — and report \((a, b)\). Interpret the fitted values: what would \(a < 1\) have fixed, and what does \(a \approx 1, b \approx 0\) (near-calibration) tell you about when post-hoc calibration is needed at all?

Hint Under heavy imbalance the raw sigmoid still ranks well but pushes probabilities toward the majority; a second sigmoid fit on held-out logits is the classical fix.
Solution
The deciles show modest overconfidence in the low bins (p̂ = 0.012–0.054 vs observed 0–0.1) — yet the global Platt fit returns \(a \approx 1, b \approx 0\): with a two-parameter monotone remap there is little to fix at this noise level. The lesson cuts both ways: local bin plots reveal miscalibration structure that a global two-parameter fix may not address, and a near-identity Platt fit certifies calibration rather than assuming it. The layered structure (representations → head → calibrator) is standard for deep nets: modern nets are excellent rankers whose probability outputs must be checked (and often Platt/temperature-scaled on held-out logits) before clinical use.

6. Complex Questions

C1 (× 3.3 × 4.4 bias–variance). You have two fits on the same data: statsmodels’ IRLS logistic regression and your 300-step GD neuron, both unregularized. For n ∈ {30, 60, 120, 240, 480}, compare test accuracy in a small simulation. Where do they differ and why — connect optimizer convergence speed to sample size (hint: at small n the variance dominates and both converge to similar fits; at large n, an under-converged GD run is the biased one).

C2 (× 5.2 ridge × 8.3 soft-margin SVM). Three linear classifiers, three penalties, one geometry: logistic+BCE (log-loss), linear SVM (hinge), ridge regression sign (squared). For the moons data with a fixed labeled outlier flipped far away, fit all three (sklearn) and overlay the boundaries. Which loss’s gradient saturates at the outlier and which grows linearly/unboundedly — and how does that explain the robustness ordering you observe? (This is hinge’s margin story from the neuron’s-eye view.)

7. Summary

  • One neuron = affine + activation; paired with the right loss it is logistic or linear regression.
  • sigmoid+BCE (softmax+CE) are matched pairs: the Jacobian cancels, leaving gradient = residual form.
  • One neuron cuts with a hyperplane — XOR-style structure needs composition (next page).
  • Saturation, scaling, and imbalance are the single-neuron’s three horsemen; standardize, match pairs, and choose thresholds deliberately.
  • Convexity guarantees no local minima — not speed, not stability, not calibration.
  • Outputs are rankers’ probabilities; calibrate on held-out data before clinical use.
  • Two neurons already beat XOR: time to stack — 10.3 multilayer networks.
