3.1 Classification Fundamentals

Classification predicts a categorical response. The output of a classifier is really two things: a score (a probability-like number per case) and a decision rule (a threshold converting scores to labels). Confusing the two is the root of most classification-metric confusion — this page separates them and builds the metric toolkit: confusion matrix, sensitivity/specificity, precision/recall, F1, and ROC.

Tier 1 — every cell below runs live.

1. Basic Concept

Every classifier worth using exposes scores. The confusion matrix tabulates decisions vs truth:

Predicted + Predicted −
Actually + TP (hit) FN (miss)
Actually − FP (false alarm) TN (correct rejection)

From it, the quartet that all others are ratios of:

\[\text{Sensitivity/Recall/TPR} = \frac{TP}{TP + FN} \quad \text{Specificity/TNR} = \frac{TN}{TN + FP}\] \[\text{Precision/PPV} = \frac{TP}{TP + FP} \quad \text{FPR} = \frac{FP}{FP + TN}\]

Accuracy folds everything into one number — and hides everything, too (3.1.5 is dedicated to that trap).

2. Concept Questions

  1. A screening test has sensitivity 0.99 and specificity 0.90. In plain words, what do those two numbers promise — and what do they not tell you about a positive result?
  2. Why can accuracy be uninformative while sensitivity/specificity stay excellent? Construct the extreme case.
  3. Your classifier’s scores get monotonically squashed (e.g. all scores squared, order preserved). Which metrics change: accuracy at t = 0.5? AUC? AP?
  4. Precision and recall pull in opposite directions as the threshold moves. State what each one’s denominators “cost” and why no single number captures both.
  5. Two models have identical AUC. Are they interchangeable? Name one axis on which they can differ.
Answers
  1. Promise: 99% of diseased people test positive (few misses); 90% of healthy people test negative. Not promised: that a positive result means disease — that’s PPV, which depends on prevalence (the Bayes result of 1.3: at 0.1% prevalence it’s ~1%… here: 0.99·0.001/(0.99·0.001+0.10·0.999) ≈ 0.98%).
  2. Extreme case: 1% prevalence, “always predict healthy” — accuracy 99%, sensitivity 0. The two class-conditional rates (sensitivity/specificity) are computed within true classes, so they’re immune to prevalence; accuracy isn’t. Report both families or use prevalence-aware metrics.
  3. Squashing destroys the absolute score scale but not the ranking. Accuracy at a fixed threshold can change arbitrarily (t = 0.5 lands somewhere new); AUC is invariant (it uses ranks only); AP likewise (rank-based). Threshold-dependent metrics care about calibration; ranking metrics don’t.
  4. Precision’s denominator (TP+FP) pays for every false alarm the threshold admits; recall’s (TP+FN) pays for every miss. Loosening the threshold admits both more TPs and more FPs — recall ↑, precision typically ↓. Their trade-off is the operating curve; F1 summarizes it at one point, losing the shape.
  5. No — AUC measures ranking quality only. They can differ wildly in calibration (does 0.8 mean 80%?), which matters for cost decisions and downstream probability uses; also in score distribution (threshold placement) and per-region behavior (one may win high-specificity operating points, the other high-sensitivity).

Drills

Exercises (with solutions)

Exercise 1. From the ranked list below, compute by hand (paper or code, no sklearn) the confusion matrix at threshold 0.5, then TPR/FPR at every possible threshold, the full ROC, and AUC via concordant pairs. Verify every number against sklearn.

Solution
The sweep logic — walk down the ranked list, accumulating hits and false alarms — is the same walk every ROC/PR implementation takes. Owning it once demystifies the curves forever.

Exercise 2. Show the threshold-cost trade in dollars: a screening context has FN cost = $2000 (missed disease), FP cost = $100 (needless follow-up), TN/FN-free = $0. Using the scores from Section 1, compute expected cost at thresholds 0.1–0.9 (step 0.1) and find the cost-optimal threshold. Compare it to the Youden-optimal threshold (max TPR − FPR) and explain when/why the two disagree.

Solution
Youden treats error types symmetrically; real costs almost never are. With FN 20× costlier than FP, the optimal threshold drops (screen loose, confirm hard). Metric choice is a decision-theory choice — there is no threshold-free “best.”

Exercise 3. Cross-validated metric honesty: generate a moderate-signal classification dataset (n = 300, 20% positives), and compare in-sample vs 5-fold-CV values of accuracy, balanced accuracy, F1, and AUC for a logistic classifier. Which metric’s in-sample–CV gap is largest, and why does AUC’s gap behave differently from accuracy’s?

Solution
All in-sample numbers are optimistic; the ranking of metrics is preserved but the gaps differ with each metric’s sensitivity to the specific borderline cases the model tuned on. AUC’s gap tracks the same overfitting — the lesson is not “trust one metric” but “compute every metric out-of-sample,” the discipline Part 4 industrializes.

4. Advanced Information & Pitfalls

  • confusion_matrix row/column convention: sklearn rows = true, columns = predicted. Transposed matrices are a classic silent error — print it once, label it forever.
  • AUC pairs with ties count 0.5 (the hand formula above); scores from a coarse model (few distinct values, e.g. a 5-bin risk score) lose AUC resolution through ties.
  • predict vs predict_proba: predict uses the (possibly inappropriate) 0.5 threshold; decision problems usually want predict_proba + your own threshold from costs (Exercise 2).
  • Macro vs micro vs weighted averaging of F1 across classes: macro treats a 2% class equally with the 98% class (each class one vote); micro ≈ accuracy. Know which your library reports by default.
  • AUC ignores calibration — great for ranking, dangerous if someone downstream multiplies your scores into decisions as if they were probabilities; calibration gets its own treatment in 3.7.
  • Class imbalance doesn’t bias AUC as an estimate of ranking skill, but its sampling noise grows as the positive count shrinks — with 10 positives, one swap changes AUC by 0.02+ (1.4 logic applies to metrics too).

5. Advanced Questions

Q1. Derive AUC as the Mann–Whitney U statistic: show that AUC = U/(n₊n₋) where U counts concordant positive-negative pairs (ties as ½), and use this to (a) prove AUC = 0.5 under exchangeable scores, (b) construct the null SD of AUC (≈ √((n₊+n₋+1)/(12·n₊·n₋))) and compute how many positives you need for AUC ± 0.05 at n₋ = 500.

Hint Each positive-negative pair contributes 1, ½, or 0 to the numerator; under the null each pair is a fair coin.
Solution By definition of the empirical ROC, each threshold pair (TPR, FPR) increment is (1/n₊, 1/n₋); the area integrates the fraction of pairs with score₊ > score₋ — exactly U/(n₊n₋). (a) Under H₀ (scores exchangeable across labels) each pair is concordant/discordant with probability ½ ⇒ E[AUC] = ½. (b) Var per pair ≈ 1/12 (variance of a fair three-way ±1/½/0 trial scaled); SD(AUC) ≈ √((n₊+n₋+1)/(12n₊n₋)). Setting 1.96·SD ≤ 0.05 with n₋ = 500: n₊ ≈ 1.96²·501/(12·500·0.05²) ≈ 128 positives. Moral: the 10-positive biomarker studies quoted with 3-decimal AUCs are noise — cite the interval, not the point.

Q2. A colleague argues: “We shouldn’t fix the threshold at 0.5; we should report sensitivity and specificity at their best threshold on the test set.” Give the two failures of this plan (optimism and interpretation), then implement the honest version: choose the threshold on a validation split, freeze it, report test-set sensitivity/specificity at the frozen threshold, and compare the two procedures’ reported numbers over 200 resamples.

Solution

Failures: (1) Selection optimism — picking the threshold that maximizes test performance then reporting that same performance is tuning on the test set (0.5); the reported best point is an extreme order statistic, biased upward. (2) Interpretation — the “best” point is noise-selected per dataset; across studies the reported sensitivity/specificity are not the same operating point, so they’re not comparable or replicable. Honest version:

The frozen threshold generalizes; the per-dataset-max procedure would report visibly rosier pairs on average (run both to see the gap). One threshold, chosen where tuning is allowed, applied where it isn’t — the Part 4 ethic in miniature.

7. Summary

  • A classifier = scores + threshold; the confusion matrix is where decisions meet truth.
  • Sensitivity/specificity are prevalence-immune; precision and accuracy are not — know which question each answers.
  • AUC = probability a random positive outranks a random negative; rank-based, threshold-free, calibration-blind.
  • Thresholds are decision-theory: costs set them, validation selects them, test sets only measure them.
  • On imbalanced data, accuracy flatters; balanced accuracy/F1/AP keep you honest.
  • All metrics inherit sampling noise — small positive counts make small AUC differences meaningless.
  • When positives get truly rare, even ROC starts flattering: the precision–recall view is next — 3.1.5 AUPRC for skewed datasets.
