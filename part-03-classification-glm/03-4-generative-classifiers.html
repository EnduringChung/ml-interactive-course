3.4 Generative Classifiers: LDA, QDA, Naive Bayes

Instead of modeling P(y|x) directly (discriminative — logistic), generative classifiers model how each class generates data — P(x|y) and P(y) — then flip the conditioning with Bayes’ rule. Three classical instances span the assumption spectrum: LDA (Gaussian, shared covariance), QDA (Gaussian, per-class covariance), Naive Bayes (conditionally independent features).

Tier 1 — every cell below runs live.

1. Basic Concept

Bayes’ rule chooses the class maximizing the posterior:

\[P(y = k \mid x) = \frac{P(x \mid y = k)\, P(y = k)}{\sum_j P(x \mid y = j)\, P(y = j)}\]

LDA assumes each class is Gaussian with its own mean μₖ but one shared covariance Σ. Plugging in and simplifying, the log-posterior becomes linear in x — hence linear discriminant. QDA gives each class its own Σₖ; quadratic terms survive — quadratic boundaries. Gaussian Naive Bayes assumes independence within each class (diagonal covariance): one variance per feature per class, no correlations — crude but fast and parameter-poor.

2. Concept Questions

  1. What does the “naive” in Naive Bayes assume, and why is it catastrophic for correlated features even when each feature is individually informative?
  2. LDA vs QDA: state the parameter-count trade (in d dimensions, per class) and the sample-size rule of thumb that follows.
  3. Why do generative models need fewer training samples to reach a given accuracy when their assumptions hold — and what happens when the assumptions don’t hold?
  4. LDA’s boundary is linear. Which two simplifications of the Bayes-optimal rule produce that linearity?
  5. Your features are 5,000 gene counts with strong correlations. Which of the three would you reach for first, and what would you need to check before trusting QDA?
Answers
  1. Features are conditionally independent given the class (diagonal class covariance). With correlated informative features, NB double-counts the same evidence: two correlated genes each “voting” for the class push the posterior toward certainty twice — overconfident probabilities, badly calibrated posteriors (accuracy can survive; the probability values don’t).
  2. LDA: one shared Σ = O(d²) parameters total + d means per class; QDA: full Σₖ per class = O(k·d²). With d = 50, LDA’s Σ has 1,275 entries shared; QDA’s two have 2,550 estimated separately. Rule of thumb (ISL): small n or a shared-covariance belief → LDA; large n or visibly different covariances → QDA. (Between them sits “regularized QDA”/shrinkage covariance.)
  3. Modeling the joint densities adds structure the data needn’t discover: with correct assumptions, the estimate converges at parametric rates and out-of-sample accuracy rises quickly with n (fewer effective parameters than a discriminative search over boundaries). When wrong, the bias is baked in — and generative models typically converge to the wrong boundary no matter how much data arrives, while flexible discriminative methods would eventually find the truth.
    1. Gaussian class densities; (b) equal covariance matrices — the quadratic terms x^TΣₖ⁻¹x then coincide across classes and cancel in the log-ratio, leaving a linear score.
  5. Gaussian NB with correlation-aware caution… honestly: none of the three directly. NB’s independence assumption is badly violated (double counting). QDA in d = 5,000 estimates 12.5M covariance entries per class — singular without regularization; you’d need heavy shrinkage (reg_param) or feature reduction first (or logistic regression with penalties — Part 5). The check before QDA: n ≫ d and covariance stability, neither plausible here.

Exercises (with solutions)

Exercise 1. Implement LDA’s classification rule from scratch for two classes: estimate μ̂₀, μ̂₁, pooled covariance Σ̂, priors; classify by sign of the linear score \(x^\top \Sigma^{-1}(\mu_1 - \mu_0) - \tfrac12(\mu_1^\top\Sigma^{-1}\mu_1 - \mu_0^\top\Sigma^{-1}\mu_0) + \log(\pi_1/\pi_0)\). Verify 100% agreement with sklearn on training data, then perturb one class’s covariance and show where LDA and QDA begin to disagree.

Solution
The hand version IS sklearn’s rule (up to internal scaling). Once covariances differ, the shared-Σ score is no longer Bayes-optimal and QDA’s quadratic terms capture the elliptical structure — visible as disagreement concentrated far from the boundary.

Exercise 2. The NB double-counting experiment, quantified: build truth where P(y=1|x) depends on a single latent z, and expose it through k increasingly correlated copies (ρ = 0, 0.5, 0.9, 1.0 between copies). For each ρ, fit GaussianNB and logistic regression; report (a) accuracy, (b) the mean predicted probability for true positives (overconfidence meter). Which model’s accuracy degrades with ρ? Which model’s probabilities degrade?

Solution
Accuracy stays similar across ρ for both (the information content doesn’t change much), but NB’s predicted probabilities inflate toward 1 as correlation grows — the same evidence counted twice. Logistic regression, discriminative, never assumed independence and stays calibrated. Lesson: choose the model by what you consume — rankings (NB fine) or probabilities (NB dangerous under correlation).

Exercise 3. Generative vs discriminative sample-efficiency sweep: fixed true model = two Gaussians with equal covariance (LDA’s world, so its assumptions hold). For n per class in {5, 15, 50, 200}, fit LDA and unpenalized logistic on 100 independent training sets, evaluate each on a fixed test set, and plot mean test accuracy vs n. Which converges faster? Then repeat with unequal covariances and re-read the curves.

Solution
Equal covariance (LDA’s assumptions true): LDA leads at every n — the generative parametric payoff. Unequal: LDA’s advantage evaporates/reverses as its bias caps its ceiling while logistic keeps climbing. The generative-vs-discriminative trade, drawn to scale.

4. Advanced Information & Pitfalls

  • LDA’s shared covariance is a modeling claim — check it (visual covariance ellipses, Box’s M in spirit) before trusting its SEs/probabilities; QDA when ellipses differ, and reg_param when n is small.
  • QDA in high dimensions is numerically fragile: per-class covariance matrices go singular (d > n per class); sklearn’s reg_param adds ridge-like stabilization — tune it, don’t disable it.
  • NB posteriors are overconfident under any correlation — never quote its probabilities without calibration checks (3.7); its rankings survive much better than its values.
  • Class priors matter: LDA/NB use empirical priors; in case–control samples the priors are sampling artifacts — correct with priors= (sklearn) or logit-offset (3.3 C2).
  • LDA is also a projector: its scalings give the k−1 discriminant axes — a supervised alternative to PCA for visualization (9.2 contrast: PCA is unsupervised, ignores y).
  • Multiclass comes free: all three handle k > 2 natively (no one-vs-rest machinery) — a quiet advantage over the logistic formulations of 3.3.

5. Advanced Questions

Q1. Derive LDA’s linear score from the Gaussian log-densities: write \(\log P(x|k) + \log \pi_k\) for class k, subtract the two classes’ expressions, and show every quadratic term cancels under Σ₀ = Σ₁. Then state precisely which direction the discriminant points (Σ⁻¹(μ₁−μ₀)) and why it is the Fisher optimal projection (maximizing between-class over within-class variance).

Hint Expand −½(x−μₖ)ᵀΣ⁻¹(x−μₖ); the xᵀΣ⁻¹x piece is class-independent.
Solution log P(x|k) = −½(x−μₖ)ᵀΣ⁻¹(x−μₖ) + constₖ. The difference log P(x|1) − log P(x|0) = xᵀΣ⁻¹(μ₁−μ₀) − ½(μ₁ᵀΣ⁻¹μ₁ − μ₀ᵀΣ⁻¹μ₀) — the xᵀΣ⁻¹x terms cancel because Σ is shared. The decision score is linear with direction w = Σ⁻¹(μ₁−μ₀): the class separation, whitened by within-class covariance — which is exactly Fisher’s criterion argmax wᵀ(μ₁−μ₀)/√(wᵀΣw). Two views, one vector: the generative derivation and the optimal-projection problem have the same solution, which is why LDA doubles as both a classifier and a supervised projector.

Q2. You have d = 2,000 features, n = 200 samples, two classes with correlated features. Design the analysis pipeline: which of LDA/QDA/NB/logistic is even feasible as-is, what preprocessing must precede it, how you’d validate the choice (0.5 + 4.6 discipline), and what failure mode each option guards against. Demonstrate with a simulation: compare the candidates’ CV accuracies and calibration under p ≫ n.

Solution

Feasibility triage: QDA — infeasible (4M covariance parameters/class, singular). LDA — pooled Σ is 2000×2000 from 200 samples: singular; needs shrinkage or feature reduction. GaussianNB — feasible (2 diag variances per class) but assumes away the correlations and p ≫ n overconfidence. Logistic with L2 penalty — feasible and standard. Pipeline: standardize → (optionally) reduce dimension (feature screening inside CV only, or PCA) → fit penalized logistic / shrunk-LDA / NB inside a Pipeline → nested CV for model choice, calibration curve at the end.

Typical outcome: penalized logistic ≈ shrunk LDA > NB on accuracy, and only logistic/LDA give trustworthy probability directions; NB’s accuracy is respectable while its probabilities are inflated. The p ≫ n moral: the choice is not “which classifier” but “which regularization + which validation” — the subject of Part 5 and Part 4 respectively.

7. Summary

  • Generative = model P(x|y)P(y), classify by posterior; fewer effective parameters, stronger assumptions.
  • LDA: shared Gaussian covariance → linear boundary + Fisher projection; QDA: per-class covariance → quadratic; NB: conditional independence → diagonal, fast, fragile probabilities.
  • LDA/QDA need n ≫ d and covariance stability (shrinkage/reg_param); NB needs feature independence to be honest.
  • Priors are parameters: sampling designs (case–control) must be corrected before quoting posteriors.
  • Correlated features double-count in NB — rankings survive, probabilities don’t.
  • Generative wins small-n under true assumptions; discriminative catches up and overtakes when assumptions fail.
  • The remaining classical classifier is assumption-free neighborhood voting: 3.5 KNN classification.
