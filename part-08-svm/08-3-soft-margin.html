8.3 The Soft-Margin Classifier

Real classes overlap. The soft margin keeps the maximal-margin idea but lets points pay a price ξᵢ to violate it — turning “impossible” into “tunable”: C sets the exchange rate between a fat margin and a clean fit. It is the SVM you will actually use.

Tier 1 — every cell below runs live.

1. Basic Concept

\[\min_{w, b, \xi} \; \frac{1}{2}\|w\|^2 + C \sum_i \xi_i \quad \text{s.t.} \quad y_i(w^\top x_i + b) \ge 1 - \xi_i, \;\; \xi_i \ge 0\]

ξᵢ = how far point i intrudes into (or crosses) the margin; C = the price per unit of intrusion. C → ∞ recovers the hard margin; C → 0 lets the boundary ignore everything.

2. Concept Questions

  1. A support vector in the soft-margin world: which points get αᵢ > 0 now? Are they all on the margin?
  2. C → ∞ and C → 0 endpoints: state both behaviors, including what the boundary does at C = 0.
  3. How does the hinge loss differ from logistic loss at (a) correctly-classified far points, (b) misclassified points — and what does each difference do to the fitted boundary?
  4. Your CV chooses C = 1000 on overlapping data. What is that telling you about the data — and is the resulting margin reportable?
  5. Why does the soft-margin SVM remain scale-sensitive, and which quantity does a feature-unit change distort — C, ξ, or both?
Answers
  1. In the hard margin, αᵢ > 0 ⟺ on the margin. Soft margin: αᵢ > 0 for points on the margin and all violators (ξᵢ > 0) — anything touching or crossing the band is load-bearing; far-correct points still don’t matter.
  2. C → ∞: slacks become unaffordable → hard-margin behavior (infeasible if overlap exists — solver strains). C → 0: violations are free → ‖w‖ → 0 dominates, boundary collapses toward arbitrary/mean — practically untrained. C = 0 exactly is degenerate (w = 0 minimizes).
    1. Hinge = 0 for far-correct points (no gradient, no influence — the margin geometry’s parsimony); logistic loss never reaches zero — every point pulls forever (smoother, no sparsity of influence). (b) Misclassified: hinge is linear in the violation (bounded influence of any single point), logistic is exponential-ish in the margin distance (a single extreme point can dominate the fit). Net: SVM boundary = geometry of the frontier; logistic boundary = a weighted average view of all data.
  4. High C chosen on overlapping data says “the CV folds are (nearly) separable under heavy penalization” — i.e., few-but-real violations. The reported 2/‖w‖ is then a nominal margin with (100·violation%) of points inside it — report it together with the violation fraction, or not at all.
  5. Both, via ξᵢ: ξᵢ is measured in score units (wᵀx + b), whose scale depends on feature units — rescaling a feature changes each ξᵢ and thus the C-price of the same geometric situation. Standardize first, always (geometric law from 8.1).

Drills

Exercises (with solutions)

Exercise 1. Hinge-loss SVM from scratch: minimize (1/2)‖w‖² + C·Σ max(0, 1 − yᵢ(wᵀxᵢ + b)) by sub-gradient descent on a small dataset; compare the resulting (w, b) and predictions to LinearSVC(C=C) (normalize for the scale convention — compare decision signs and margin geometry, not raw coefficients). Report where your solution and sklearn’s agree and where optimization details diverge.

Solution
Sub-gradient descent on the hinge objective converges to the same margin geometry (same direction; coefficient scale conventions differ between formulations — that’s why you compare normalized geometry). sklearn’s solver is faster and smarter, but you’ve now implemented the objective the whole method optimizes.

Exercise 2. The C-frontier: on overlapping data, sweep C over 6 log-spaced values; for each record (a) training margin-violation fraction, (b) train accuracy, (c) test accuracy, (d) ‖w‖. Plot the panel. Identify the three regimes (underfit-all-slack / balanced / overfit-margin) and connect each to its bias–variance signature (4.4) — C is SVM’s flexibility dial, running opposite to k in KNN or… specify the direction relative to ridge’s λ.

Solution
Small C: everything is slack, ‖w‖ tiny — underfit (bias-dominated). Large C: margin tight, boundary chases the frontier points — variance-dominated. Balanced middle: few violations, stable boundary. Relative to ridge (5.2): C is 1/λ — big C = weak regularization; the dial’s direction is inverted, which trips everyone once.

Exercise 3. Soft margin under label noise: inject 8% label flips into separable data. Compare hard-margin-attempt (C = 1e5) vs CV-tuned soft margin: test accuracy, boundary angle between them, and the fraction of flipped points that became support vectors. Then explain why the tuned soft margin absorbs the noise while the hard attempt contorts around it — and which of the two would you trust under 3.2’s class-overlap realities.

Solution
Flipped labels sit deep in enemy territory; a hard margin bends the boundary extravagantly to accommodate them (or fails); a tuned soft margin prices them as ξ and lets them sit violated — boundary stays where the clean mass of evidence points. Trust the soft margin: label noise is precisely the violation-budget use case, and C is the honest knob declaring how much noise you’ll tolerate.

4. Advanced Information & Pitfalls

  • C’s direction vs every other penalty: C is 1/λ — larger = less regularized. Writing “higher C = more regularization” in a report is the classic tell of a rushed pipeline.
  • Violating support vectors: in soft-margin fits, αᵢ is capped at C; points with αᵢ = C are the ξᵢ > 0 violators. Reading dual_coef_ magnitudes against C tells you which SVs are on-margin vs crossing.
  • LinearSVC has no predict_proba — probability-ish outputs need SVC(probability=True) (Platt scaling, internal CV) or a separate calibrator (3.7); don’t pretend decision_function values are probabilities.
  • Class weights rescale C per class: class_weight={1: 5} multiplies minority violations’ price — the margin version of imbalance handling (3.1); evaluate with PR metrics.
  • Hinge loss ⇒ no probabilities and non-smooth optimization: that’s the price of margin sparsity; the logistic comparison (8.5) is exactly hinge-vs-log.
  • Multiclass: SVC runs OvO internally (8.6) — C’s meaning per binary subproblem, aggregated.

5. Advanced Questions

Q1. Connect the two formulations: show that the ξ-form (min ‖w‖²/2 + CΣξᵢ) is identical to unconstrained hinge minimization (1/2)‖w‖² + CΣmax(0, 1 − yᵢfᵢ) — by substituting ξᵢ = max(0, 1 − yᵢfᵢ) and checking the optimal ξᵢ given (w, b). Then verify numerically: solve both with scipy for a tiny problem and compare (w, b) up to solver tolerance. What does this equivalence buy conceptually (loss view vs constraint view)?

Hint For fixed (w, b), the constraint set forces ξᵢ ≥ 1 − yᵢfᵢ and ξᵢ ≥ 0; minimizing Cξᵢ picks exactly the hinge value.
Solution Given (w, b), the smallest feasible ξᵢ is max(0, 1 − yᵢ(wᵀxᵢ + b)) — substituting and dropping ξ turns the constrained program into unconstrained hinge minimization. The views are dual lenses: the constraint view exposes geometry (margins, SVs, KKT); the loss view exposes optimization (subgradients, SGD, loss comparisons with logistic — 8.5). Solvers like LinearSVC optimize the hinge directly; SVC optimizes the dual of the ξ-form — same optimum, different algebra.

Q2. C vs the bias–variance decomposition: estimate bias² and variance of the soft-margin SVM across C ∈ {0.01, 1, 100} using the multi-training-set protocol (4.4) on overlapping data. Which C minimizes variance, which minimizes bias², and does total error’s minimum sit at the CV-chosen C? Write the sentence connecting C to the decomposition — the SVM’s own bias–variance story.

Solution
Small C: heavy slack tolerance → boundary drifts freely (high variance in position is capped, but bias rises as the fit under-commits). Large C: tight margins fit each sample’s frontier (variance up), bias lower. The CV-chosen C typically sits at the decomposition’s total-minimum — the SVM’s C is its bias–variance dial, in constraint language.

7. Summary

  • Soft margin = hard margin + slack budget: min ‖w‖²/2 + CΣξᵢ — the SVM for real, overlapping data.
  • Hinge loss is the same object unconstrained: zero for far-correct points, linear when wrong.
  • C is the slack price — 1/λ: larger C = weaker regularization; the inverted direction trips everyone.
  • Support vectors now include violators; far-correct points still don’t matter.
  • C is the SVM’s bias–variance dial; CV picks it; margins reported alongside violation fractions.
  • No native probabilities — calibrate or quote scores as scores.
  • Linear soft margins in hand, the nonlinear leap costs one substitution: 8.4 Kernel SVM.
