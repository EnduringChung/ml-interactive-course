1.3 Probability Essentials

Probability is the language in which every model speaks: a predicted probability, a p-value, a 95% interval, a likelihood. This page drills the rules, the three distributions that do most of the work in ML (binomial, Poisson, normal), and the one formula — Bayes’ rule — that most people’s intuition gets wrong.

Tier 1 — every cell below runs live.

1. Basic Concept

The rules. For events A and B:

  • Complement: \(P(A^c) = 1 - P(A)\) — “at least one” questions become “1 minus none.”
  • Addition: \(P(A \cup B) = P(A) + P(B) - P(A \cap B)\) — the intersection is counted twice, subtract once.
  • Multiplication / conditioning: \(P(A \cap B) = P(A \mid B)\,P(B)\); independence means \(P(A \cap B) = P(A)P(B)\), so for independent events conditioning changes nothing.
  • Bayes: \(P(A \mid B) = \dfrac{P(B \mid A)\,P(A)}{P(B)}\) — the flip between “evidence given cause” and “cause given evidence.”

Random variables and their machines. A distribution assigns probability to outcomes. The three workhorses:

Distribution Models Parameters scipy
Binomial # successes in n independent yes/no trials n, p stats.binom
Poisson # events in fixed time/space (counts, reads) λ (rate) stats.poisson
Normal sums/averages of many small effects (CLT) μ, σ stats.norm

Expectation and variance are the distribution’s center and spread: \(E[X] = \sum x\,p(x)\); for the sum of independent variables, means add and variances add (this additive rule powers everything from portfolio risk to the SE of a mean).

2. Concept Questions

  1. A test is 99% sensitive and 99% specific; prevalence is 1/1000. Roughly what fraction of positive results are true positives, and which two quantities fought each other in the Bayes computation?
  2. When does Poisson model counts well, and what does it assume that binomial does not?
  3. What is P(X = 4.0) for a continuous random variable, and what do we evaluate instead?
  4. Why do variances add but standard deviations don’t?
  5. If A and B are independent with P(A) = 0.5, P(B) = 0.8, what is P(A ∪ B)?
Answers
  1. About 9%. The fight: the evidence actually observed (true positives, \(0.99 \times 0.001\)) versus the much larger pool of false positives generated by the huge healthy majority (\(0.01 \times 0.999\)). Base rate dominates when prevalence is low.
  2. Poisson fits counts of events in a fixed window when events are rare and independent (reads overlapping a gene, mutations per kb). It assumes events occur with a constant rate and no upper bound; binomial counts successes in a fixed number of trials n.
  3. Zero — a point has no width, so its probability mass is 0. We evaluate \(P(X \le x)\) (CDF) or \(P(a < X < b)\) (density integrated over the interval).
  4. Variance adds because the cross-terms of independent variables average to zero: \(\text{Var}(X+Y) = \text{Var}(X)+\text{Var}(Y)\). SD is the square root of that sum, and square roots don’t add: \(\sqrt{a+b} \ne \sqrt a + \sqrt b\).
  5. \(P(A\cup B) = 0.5 + 0.8 - 0.5\times0.8 = 0.9\).

Drills

Predict, then run.

Exercises (with solutions)

Exercise 1 — the full Bayes computation. Disease prevalence 0.1%, test sensitivity 99%, specificity 99%. Compute (a) P(disease | positive), (b) the same for prevalence 10%, (c) how high specificity must be at 0.1% prevalence for PPV ≥ 50%. State each result as one sentence.

Solution
  1. 9% — a positive result is usually false at 0.1% prevalence. (b) 92% — the same test is excellent in a high-risk population. (c) specificity ≈ 99.90% — the false-positive rate per healthy person must be driven below the true prevalence. Same machine, three different decisions — this is why screening policies depend on prevalence, not just on test quality.

Exercise 2 — Monte Carlo verification. Verify analytically-computed probabilities by simulation: (a) at least one six in 4 rolls; (b) P(Binomial(20, 0.3) ≥ 10); (c) P(Normal(0,1) within ±1.5). Report simulated vs exact to 3 decimals.

Solution
Note the pattern — sf(9, ...) for “≥ 10” (sf is P(X > k), so use k−1). Monte Carlo with N = 10⁶ carries ~0.05% MC error; agreement to 3 decimals is expected, and this verify-by-simulation habit will debug countless probability computations later.

Exercise 3 — the law of total probability in a lab setting. 1% of samples are contaminated. Contaminated samples fail QC 80% of the time; clean samples fail 2% of the time. What fraction of samples fail QC? Given a sample failed QC, what’s the probability it was contaminated?

Solution
Two-step structure: total probability pools the failure rate across the two sample types; Bayes re-weights to ask about the cause. Even a 40× higher failure rate for contaminated samples only gets you to 27% — because clean samples are 99× more numerous. Always ask what population produced this positive.

4. Advanced Information & Pitfalls

  • P(A|B) vs P(B|A) — transposing the conditional is the prosecutor’s fallacy; DNA-match statistics are its most famous victim. Every Bayes computation should start by naming which conditional you have and which you want.
  • Independence is not “small correlation” and not “no obvious relationship” — it is \(P(A \cap B) = P(A)P(B)\) exactly. Rarely true for biological measurements (batch, relatedness, shared environment).
  • pdf values are not probabilities — stats.norm.pdf(0) ≈ 0.4 yet P(X=0) = 0; the density integrates to probability. Only CDFs and intervals carry probability meaning.
  • sf(k) = P(X > k) (strictly greater) — the classic off-by-one: P(X ≥ 10) = sf(9), not sf(10). Write the inequality before writing the function call.
  • Poisson has variance = mean; real count data routinely violates this (overdispersion) — the reason negative-binomial models exist in RNA-seq DE analysis (12.6).
  • CLT applies to standardized sums of many independent contributions — not to heavy-tailed data at small n, and not to highly skewed counts at n = 5.

5. Advanced Questions

Q1. Derive the 9% PPV result symbolically and explain in terms of the Bayes numerator and denominator why increasing sensitivity barely helps at low prevalence, while increasing specificity helps enormously.

Hint Write PPV \(= \frac{sp\,\pi}{sp\,\pi + (1-sc)(1-\pi)}\) and ask: which term shrinks when sens ↑ vs spec ↑, at \(\pi = 0.001\)?
Solution PPV \(= \dfrac{\text{sens}\cdot\pi}{\text{sens}\cdot\pi + (1-\text{spec})(1-\pi)}\). At \(\pi = 0.001\): the numerator term is ≈ sens × 0.001 — small no matter how good sens is (bounded by prevalence itself). The denominator’s second term is \((1-\text{spec}) \times 0.999\) — nearly the whole healthy population times the false-positive rate. Raising sens 0.99 → 0.999 multiplies the numerator by ~1.009; raising spec 0.99 → 0.999 divides the false-positive term by 10. At low prevalence, PPV is governed by specificity — which is why screening programs chase specificity and why confirmatory (more specific) tests follow any positive screen.

Q2. Two independent watchtowers detect fires with probabilities 0.8 and 0.7 respectively. Given exactly one detection occurred, what is the probability it was tower 1? Compute symbolically and verify by Monte Carlo.

Hint Enumerate the four detection outcomes with their probabilities; condition on the two “exactly one” outcomes.
Solution

Outcomes: both \(= 0.8 \times 0.7 = 0.56\); neither \(= 0.2 \times 0.3 = 0.06\); only-1 \(= 0.8 \times 0.3 = 0.24\); only-2 \(= 0.2 \times 0.7 = 0.14\). Given “exactly one”, it was tower 1 with probability \(0.24/(0.24 + 0.14) = 0.632\).

Note the method: enumerate + condition, or simulate — both beat formula-hunting when the event structure gets any more complicated.

6. Complex Questions

C1 (probability × 0.5 Data splitting). A test set has n = 50 samples with true accuracy p = 0.8. Compute the exact probability (binomial) that the measured accuracy is ≥ 0.9 (i.e., ≥ 45 correct). Now compute the same for n = 500. What does each number say about the credibility of “90% accuracy!” claims at the two sample sizes — and connect this to the binomial SE formula used in 0.5 Q2.

C2 (probability × 12.4 FDR preview). You test 10,000 genes for differential expression at α = 0.05; none are truly differential. (a) How many false positives do you expect? (b) What’s the probability of at least one? (c) If 100 are truly differential with 80% power, what is the positive predictive value of your “significant” list? This single calculation is the entire motivation for FDR correction — predict what q-values do before learning them.

7. Summary

  • Complement turns “at least one” into “1 − none”; addition subtracts the double-counted intersection.
  • Conditional probability is the primary object; independence is \(P(A \cap B) = P(A)P(B)\), not an adjective.
  • Bayes’ rule converts P(evidence|cause) to P(cause|evidence); at low prevalence, specificity dominates PPV.
  • Binomial = n trials; Poisson = counts in a window (variance = mean); Normal = the CLT’s destination.
  • pdf values are densities, not probabilities; CDF/sf carry probability, and sf is P(X > k) — mind the off-by-one.
  • Variances add for independent sums; SDs don’t.
  • Verify any analytic probability with a Monte Carlo one-liner — cheap, and it catches unit/interval bugs.
