2.1 The Regression Problem

Regression is the archetypal supervised-learning problem: given inputs \(X\), predict a quantitative response \(Y\) by estimating the underlying function \(f\) with a model \(\hat{f}\) trained on data. Every idea in this course — loss, generalization, bias–variance, tuning — can be seen first through this lens.

Tier 1 — every cell below runs live.

1. Basic Concept

We assume data is generated as

\[Y = f(X) + \varepsilon, \qquad \mathbb{E}[\varepsilon \mid X] = 0\]

where \(f\) is the systematic part (what we want to learn) and \(\varepsilon\) is irreducible error (measurement noise, unmeasured variables). We estimate \(\hat{f}\) from training data and measure quality by a loss; for regression, the standard is squared error, whose average on new data is the mean squared error:

\[\text{MSE} = \frac{1}{n}\sum_i \big(y_i - \hat{f}(x_i)\big)^2\]

Two distinct goals (ISL’s famous dichotomy — know which one you are doing):

  • Prediction: \(\hat{Y} = \hat{f}(X)\) for new \(X\) — interpretability optional, accuracy paramount.
  • Inference: which predictors matter, how, and with what uncertainty — a mis-specified-but-interpretable \(\hat f\) can be worse than useless even if it predicts well.

The regression task: from the dots alone, recover an approximation of the curve.

Reducible vs irreducible error. Even a perfect \(\hat f = f\) leaves MSE \(= \text{Var}(\varepsilon)\). Model improvements can only shrink the reducible part. This decomposes (proved via a completing-the-square argument in 4.4 Bias–variance):

\[\mathbb{E}\big[(Y - \hat{f}(X))^2\big] = \underbrace{\big(f(X) - \mathbb{E}\hat{f}(X)\big)^2}_{\text{bias}^2} + \underbrace{\text{Var}\big(\hat{f}(X)\big)}_{\text{variance}} + \underbrace{\text{Var}(\varepsilon)}_{\text{irreducible}}\]

2. Concept Questions

  1. Your model’s test MSE is 2.31 and you estimate \(\text{Var}(\varepsilon) = 2.25\). How much room is left for model improvement?
  2. Give one scenario where a highly interpretable but slightly-less-accurate model is the right choice, and one where it is not.
  3. Is \(f\) observable? Is \(\hat f\)? What dataset do you need to evaluate \(\hat f\)?
  4. Why is squared error the conventional loss? Name one situation where it is a poor match.
  5. In \(Y = f(X) + \varepsilon\), what role does \(\mathbb{E}[\varepsilon \mid X] = 0\) play?
Answers
  1. \(\text{MSE} \ge \text{Var}(\varepsilon)\) always, so the reducible gap is \(2.31 - 2.25 = 0.06\) — the model is within 6% of the noise floor. Chasing further gains with the same features is wasted effort; collect better features or accept the limit.
  2. Yes: clinical dosing or credit decisions, where the model must be audited and each coefficient argued. Not: real-time image tagging, where nobody reads the model and only accuracy matters.
  3. \(f\) is never observed; \(\hat f\) is computed from training data. To evaluate it honestly you need data not used in fitting (0.5 Data splitting) — evaluating on training data measures memorization.
  4. Squared error is smooth, differentiable, corresponds to Gaussian-noise MLE (A.2 in the appendix), and treats errors symmetrically — but a single outlier contributes quadratically, so for heavy-tailed or gross-error settings, absolute loss or Huber loss fits better (and then “best” means a different model: median regression).
  5. It makes \(\varepsilon\) noise, not bias: the mean of the error is zero at every \(X\), so all systematic structure lives in \(f\). If violated (e.g. calibration drift), the whole decomposition and OLS theory sit on sand.

Drills

Exercises (with solutions)

Exercise 1. Generate \(n = 100\) points from \(y = 1 + 2x + \varepsilon\), \(\varepsilon \sim N(0, 4)\). Fit a line with np.polyfit, then report (a) training MSE, (b) fresh test MSE on 10,000 new points, (c) the theoretical noise floor \(\sigma^2\). Which of the two MSEs is closer to the floor, and why — what is the name of that gap?

Solution
Test MSE is closer to the floor but sits above it: training MSE is optimistically biased (the fit adapted to training noise — in-sample optimism), while test MSE = bias² + variance + σ² with small bias² and variance for a well-specified linear model. The excess over 4.0 is reducible error (here: estimation variance, shrinking with n).

Exercise 2. Prediction vs inference framing: you have hours_studied and exam_score data (generated below with a ceiling at 100). Fit a line, predict for hours = 5 and hours = 30, and explain which prediction is trustworthy, which is nonsense, and which word describes the failure (2.2 formalizes it).

Solution
hours = 5 is interpolation — inside the training range (0–12), trustworthy within uncertainty. hours = 30 is extrapolation — 2.5× beyond the observed range; the model silently reports ~175, physically impossible (score caps at 100). The word: extrapolation. Linear models extend the fitted pattern blindly; domain limits must be imposed by the analyst.

Exercise 3. Implement a regress_compare(y_true, y_pred_a, y_pred_b) helper returning MSE, RMSE, and MAE for two competing predictors, and use it to compare the mean-predictor vs the median-predictor on lognormal data. Which loss does each predictor win, and what does that tell you about the mean–median–loss triangle from 1.1?

Solution
The mean-predictor minimizes MSE and the median-predictor minimizes MAE — each wins its own column (check: mean-pred beats median-pred on MSE, median-pred beats mean-pred on MAE). “Which predictor is better” is ill-posed until you name the loss; this is the predictive face of the robustness trade-off from 1.1.

4. Advanced Information & Pitfalls

  • In-sample (training) MSE is always optimistic — the model was chosen to make it small. The gap between training and test error is optimism, and estimating it is half of Part 4.
  • Extrapolation is silent: linear models return values outside any observed region with total confidence. Always compare prediction ranges against training ranges.
  • The noise floor is a feature of the data, not the model — before tuning hyperparameters for hours, estimate \(\sigma^2\) (replicates, domain knowledge, or residual variance from a saturated fit) and ask what’s left to gain (Concept Question 1).
  • MSE vs RMSE: RMSE is in y-units (reportable), MSE is differentiable-friendly and decomposable (math-friendly). Don’t average RMSEs across folds — average MSEs, then take the root.
  • y_true - y_pred sign conventions flip between residual-as-truth-minus-fit and fit-minus-truth; squared losses don’t care, but printed residual diagnostics do — know your library’s convention.
  • Prediction vs inference changes pre-processing rules: dropping a confounded-but-predictive variable is fine for pure prediction and fatal for inference (2.5).

5. Advanced Questions

Q1. Show that the function \(c \mapsto \frac{1}{n}\sum (y_i - c)^2\) is minimized at \(c = \bar{y}\), and use this to explain why the mean-model’s training MSE equals the sample variance (drill above). What is the analogous statement for the median and MAE?

Hint Differentiate in \(c\); you already proved the median version in 1.1 Q1.
Solution \(\frac{d}{dc}\sum(y_i-c)^2 = -2\sum(y_i - c) = 0 \Rightarrow c = \bar y\); substituting back gives \(\frac{1}{n}\sum(y_i - \bar y)^2\), the (population-formula) sample variance. So the intercept-only least-squares model is the sample mean, and its in-sample MSE is the variance — which is exactly why \(R^2 = 1 - \text{RSS}/\text{TSS}\) compares every model against this null (2.4). The MAE analog: constant predictors are minimized by the median, with in-sample MAE = mean absolute deviation.

Q2. A colleague reports: “train MSE 0.9, test MSE 4.1, estimated σ² = 4.0 — my model is optimal, no more work needed.” Evaluate all three numbers as evidence. What additional split or sample-size information would sharpen the claim?

Solution Test MSE 4.1 ≈ σ² = 4.0 suggests the reducible part is tiny — if the estimate is trustworthy. But (1) a single test split’s MSE has sampling noise (its own SE ≈ σ²·√(2/n_test) under normality — a 100-point test set gives ±0.56 at 1 SE, so 4.1 vs 4.0 is inconclusive); (2) train MSE 0.9 ≪ 4.0 shows substantial in-sample optimism, meaning the model has meaningful variance (complexity) — the test error could still be lowered by regularization or a simpler model family even if it’s near the floor on average; (3) σ² estimated how? If from training residuals of the same model, it inherits the model’s bias (under-specified models inflate apparent σ²). Sharpening: K-fold CV for a stable test estimate, a proper noise estimate (replicates), and n_train/n_test sizes to judge estimation variance.

7. Summary

  • Regression = estimating \(f\) in \(Y = f(X) + \varepsilon\) from data; quality = MSE on data not used for fitting.
  • \(\text{Var}(\varepsilon)\) is the floor: model work shrinks only bias and variance, never the floor.
  • Prediction and inference are different games; they impose different rules on feature choice and reporting.
  • Training MSE is optimism in numbers; test MSE is the only honest currency (Part 4 prices it).
  • The mean-model is least squares’ null hypothesis; \(R^2\) is measured against it.
  • Extrapolation is silent failure — police the input range.
  • With the target defined, 2.2 Simple linear regression builds the first — and still most interpretable — estimator of \(f\).
