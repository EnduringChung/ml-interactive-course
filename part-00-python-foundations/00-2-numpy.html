0.2 NumPy

NumPy is the foundation of the entire Python scientific stack: pandas, scikit-learn, statsmodels, and PyTorch all speak NumPy arrays. The core skill is not memorizing functions — it is learning to think in whole-array operations instead of element-by-element loops.

Tier 1 — every cell below runs live. Predict, then run.

1. Basic Concept

A NumPy ndarray is an N-dimensional grid of values that are all the same type (dtype), stored in one contiguous block of memory. Because the data is homogeneous and contiguous, operations can be dispatched as compiled loops over memory — this is vectorization, and it is typically 10–100× faster than a Python loop.

2. Concept Questions

  1. What are the three attributes that describe an array’s structure?
  2. Why is np.array([1, 2, 3]) * np.array([10, 20, 30]) not the dot product, and what is it?
  3. Which shapes can broadcast together: (4, 3) with (3,)? (4, 3) with (4,)?
  4. What does axis=0 mean when calling .sum() on a 2-D array?
  5. a = np.arange(5); b = a[::2]; b[0] = 99 — did a change? Why?
Answers
  1. shape (size per axis), dtype (element type), ndim (number of axes).
  2. * on arrays is elementwise multiplication → [10, 40, 90]. The dot product is a @ b → 140.
  3. (4, 3) with (3,): yes — (3,) is treated as (1, 3) and broadcasts across rows. (4, 3) with (4,): no — right-aligned, 3 vs 4 conflict → ValueError. Fix by making it a column: x[:, None] or x.reshape(-1, 1).
  4. Collapse axis 0, i.e. reduce across rows, producing one value per column.
  5. Yes. Basic slicing returns a view sharing memory with a, so writing to b writes to a. Use b = a[::2].copy() when you need independence.

4. Advanced Information & Pitfalls

  • Views vs copies. Slicing returns a view (memory shared, mutating it mutates the parent); fancy indexing and boolean masking return copies. Silent aliasing bugs look like “my data changed itself.”
  • Integer overflow is silent. np.array([127], dtype=np.int8) + np.int8(1) wraps to -128 with no warning. NumPy does not upcast like Python ints.
  • NaN poisons aggregates. np.mean of an array with one NaN is NaN. Use the nan* family (np.nanmean, np.nansum) — but think about why values are missing before averaging around them (see 9.3 Missing values later in the course).
  • rng.integers(low, high) is high-exclusive; rng.random() spans [0, 1). Off-by-one here produces subtly wrong simulations.
  • Broadcasting errors vs broadcasting bugs. Shape mismatches raise loud errors, but compatible misaligned shapes (e.g. (4,1) vs (4,)) broadcast “successfully” into something semantically wrong. Print .shape when results look insane.
  • np.round uses round-half-to-even, unlike naive expectations (np.round(2.5) → 2.0). Same rule as Python’s built-in round.
  • Floating-point comparison: (a - b) == 0 fails for computed floats; use np.isclose / np.allclose for arrays.

This AI-generated “normalizer” has three bugs. Run it, diagnose, fix.

What’s wrong, and the fixed version
  1. Wrong axis / loop mindset: it claims to normalize rows but computes statistics over X[:, j] — columns. For this square matrix the result is column z-scores, exposed by the two checks: row means are not 0, column SDs are 1. (On a non-square matrix the claim and code would diverge even more visibly.) The double loop is also exactly what NumPy exists to avoid.
  2. No invariant check in the original: whoever ran this trusted it because column-SD printed 1s — a check that passes while testing the wrong axis. Always assert the invariant that matches the claim (row means ≈ 0 for row normalization).
  3. int8 overflow: values are within int8 range at construction, but adding 10 in int8 arithmetic wraps past 127 into negatives, silently. Cast to a wider dtype first.
And the honest one-liner replacing the whole loop: (X - X.mean(axis=1, keepdims=True)) / X.std(axis=1, keepdims=True).

5. Advanced Questions

Q1. Why is x[:, None] the standard fix when (n,) fails to broadcast against (n, m)? Explain using the right-to-left alignment rule, and give the two operations for which this asymmetry matters most (column-scaling and row-scaling).

Hint Draw (n,) as (1, n) after alignment and ask which axis it then stretches along.
Solution Right-aligned, (n,) behaves like (1, n): it varies along columns, so M + v adds v[j] to every row’s j-th entry (row-constant). To scale/shift per row (statistics across columns), you need a (n, 1) array: x[:, None] inserts an axis so the vector varies down rows and broadcasts across columns. It matters most in (1) M - M.mean(axis=1, keepdims=True)-style centering and (2) distance computations A[:, None, :] - B[None, :, :]. The general discipline: every broadcast bug is a shape bug — print shapes, don’t guess.

Q2. np.arange(0, 1, 0.1) and np.linspace(0, 1, 10) look like they should produce the same thing. Explain the actual difference and why linspace is preferred for evenly spaced sampling in continuous ranges.

Hint How does each decide the step size, and which endpoint is excluded?
Solution arange(start, stop, step) computes values as start + k*step and excludes stop, accumulating floating-point step error along the way — so np.arange(0, 1, 0.1) yields 10 points ending at ≈0.9 (and can even produce a surprising extra point when the step doesn’t divide the range cleanly). linspace(start, stop, num) takes the count of points and includes both endpoints by default, placing them by index division so spacing is as even as binary floats allow. Rule of thumb: arange for integer steps (e.g. np.arange(10)), linspace for float sampling of an interval.

7. Summary

  • An ndarray is a homogeneous, contiguous grid: shape, dtype, ndim describe everything.
  • Vectorization pushes loops into compiled code — think in whole-array expressions.
  • Broadcasting aligns shapes from the right; 1s stretch; make column vectors with x[:, None].
  • Slices are views, masks/fancy indices are copies; keepdims=True keeps broadcasting honest.
  • Booleans sum as 1/0: (cond).mean() is an estimator, not a trick.
  • Watch int8 overflow, NaN-poisoned aggregates, exclusive high in integers, and banker’s rounding.
  • Arrays hold the numbers; labeled data with mixed types needs pandas — next page.
