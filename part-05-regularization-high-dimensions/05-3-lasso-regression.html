5.3 Lasso Regression

The lasso (least absolute shrinkage and selection operator) penalizes the sum of absolute coefficients. The kink at zero that ‖β‖₁ introduces does something ridge never does: it sets coefficients exactly to zero — shrinkage and variable selection in one convex problem, and the workhorse of p ≫ n data.

Tier 1 — every cell below runs live.

1. Basic Concept

\[\hat{\beta}^{\text{lasso}} = \arg\min_\beta \Big\{ \sum_i (y_i - \beta_0 - x_i^\top\beta)^2 + \lambda \sum_j |\beta_j| \Big\}\]

No closed form in general (the absolute values aren’t differentiable at zero) — solved by coordinate descent: iterate coefficients one at a time, each update a soft-threshold of the OLS-style partial fit. For orthonormal X the solution is explicit and illuminating:

\[\hat\beta_j = S_\lambda(b_j) = \text{sign}(b_j)\,\max(|b_j| - \lambda,\ 0)\]

— shrink small things to zero, shrink large things by λ:

2. Concept Questions

  1. Why does the L1 penalty produce exact zeros while L2 never does? (Use the soft-threshold formula’s kink.)
  2. sklearn’s LassoCV selects alpha by CV. What does that alpha optimize, and what does it not optimize?
  3. Two features are near-perfect duplicates and both truly matter. What does lasso do, and is the resulting model wrong?
  4. Your lasso selects 4 features; you then report those 4 features’ p-values from a fresh OLS on just them. What’s still wrong?
  5. As n grows with fixed true sparsity, what happens to lasso’s selection consistency — and which condition on the design can break it (the “irrepresentable” idea, in one sentence)?
Answers
  1. For βⱼ near 0, the L2 penalty’s gradient 2βⱼ → 0 — nothing forces an exact zero (flat, smooth approach). The L1 gradient near zero is sign(βⱼ)·λ — a constant push through zero; the optimum sits at 0 unless the data strongly objects. Zero is a corner, and optima sit at corners.
  2. It optimizes prediction error (default MSE) estimated by CV over the alpha grid. It does not optimize the selected set’s correctness, coefficient unbiasedness, or any inferential property — a good predictive alpha can over- or under-select features relative to the truth.
  3. It picks (essentially) one of the duplicates and zeros the other. The model is not wrong predictively — the kept twin carries the shared signal. It’s wrong interpretively if you conclude “feature A matters, feature B doesn’t”: B is shadowed, not exonerated (2.5’s collinearity in L1 clothing).
  4. The selection step used y (through the lasso), so the refit p-values still condition on a data-chosen set — naive OLS inference after selection is invalid (5.1’s post-selection problem; lasso doesn’t escape it, it’s just smoother). Options: split-sample selection/inference, or selective-inference machinery.
  5. With n → ∞, lasso can consistently recover the true support if the design satisfies the irrepresentable condition — loosely, no feature outside the support may be too correlated with the selected set (the signal must be unambiguous). With strongly correlated “shadowed” features, lasso selection stays inconsistent even as n grows.

3. Drills & Exercises

Drills

Predict, then run.

Exercises (with solutions)

Exercise 1. Derive the soft-threshold update: for a single coefficient βⱼ with residual partial correlation fixed (others held), write the objective as a quadratic in βⱼ plus λ|βⱼ|, minimize over βⱼ > 0 and βⱼ < 0 separately, and show the solution is \(S_\lambda(z_j)\) where \(z_j = x_j^\top r_{-j} / (x_j^\top x_j)\) (r₋ⱼ = partial residuals). Then implement one full coordinate-descent pass on a small dataset and verify the objective decreases at every step.

Solution

Holding other coefficients fixed, the objective in βⱼ is \(\frac{1}{2}x_j^\top x_j\,\beta_j^2 - z_j'\beta_j + \lambda|\beta_j| + \text{const}\) (where z′ absorbs the current partial residual). For βⱼ > 0 the minimizer is (z′ − λ)/(xⱼᵀxⱼ); for βⱼ < 0 it’s (z′ + λ)/(xⱼᵀxⱼ); if the unconstrained optimum lies within ±λ, the corner βⱼ = 0 wins — assembling to the soft-threshold.

Each coordinate’s update is the exact minimizer along that coordinate, so convexity guarantees the objective never rises — the guarantee coordinate descent rides on. (The threshold is λ/(xⱼᵀxⱼ) in coefficient units: bigger columns pay proportionally less — one reason practitioners standardize.)

Exercise 2. Lasso vs ridge on sparse truth with junk: n = 80, p = 40, truth uses 3 features. Fit ridge (α tuned by CV) and lasso (LassoCV); compare test MSE on fresh data AND the number of nonzero coefficients. Then flip the truth to dense (all 40 features with small effects) and re-run. Which method wins under which truth, and what does the loser’s nonzero count say about it?

Solution
Sparse truth: lasso’s MSE is competitive-or-better and its nonzero count ≈ the truth — the interpretability win is free. Dense truth: ridge typically edges out lasso on MSE, and lasso’s nonzero count shows it dropped many small-but-real effects (bias on dense signals). The methods embody priors about the world; pick by which prior matches, verified by CV — never by leaderboard reflex.

Exercise 3. The relaxed lasso (post-lasso refit): run LassoCV to select a support; then refit plain OLS on the selected features only. Compare on fresh test data: lasso’s predictions, the relaxed fit’s predictions, and (a) MSE, (b) the relaxed coefficients vs the truth (when you know it). Why does the refit usually reduce shrinkage bias without reintroducing much variance — and when could it blow up?

Solution
Once the support is (mostly) right, refitting OLS on p_support ≪ n parameters removes the lasso’s deliberate shrinkage bias at little variance cost — that’s the relaxed lasso idea. It blows up when the support is wrong or barely stable: the selected set’s near-duplicates recreate collinearity, and selection noise propagates into the refit (which is why the relaxed variant should itself be CV’d against plain lasso, and why 5.1’s selection-uncertainty warnings still apply).

4. Advanced Information & Pitfalls

  • Standardize before lasso, always — the penalty counts coefficient magnitudes; unstandardized lasso selects by units, not information.
  • sklearn’s Lasso may not converge silently on correlated data at small alphas — watch ConvergenceWarning, raise max_iter, and prefer LassoCV (which handles warm starts and selection).
  • Alpha’s scale is objective-dependent (sklearn uses 1/(2n)·RSS + α‖β‖₁): alphas are not portable across n, feature scaling, or libraries — retune everywhere.
  • Selection ≠ inference: lasso p-values require selective-inference methods or sample splitting (5.1); a selected feature’s “significance” from a naive refit is doubly data-used.
  • Under correlation, lasso’s choice among twins is unstable — selection frequencies across bootstraps (5.1 drill) are the honest report; elastic net (5.4) is the structural fix.
  • The oracle doesn’t always appear: lasso consistency needs the irrepresentable condition; under violation it selects extras or misses features even at huge n. Don’t promise “lasso finds the true variables” in any write-up.
  • Orthonormal-case intuition is honest intuition: soft-thresholding explains every qualitative behavior (zeros, uniform shrinkage, twin coin-flips via correlated columns breaking orthonormality).

5. Advanced Questions

Q1. Prove the orthonormal-case soft thresholding: for X with orthonormal columns, the lasso objective separates across coordinates into \(\frac{1}{2}(b_j - \beta_j)^2 + \lambda|\beta_j| + \text{const}\) where \(b_j = x_j^\top y\). Solve each 1-D problem by cases and assemble \(S_\lambda(b)\). Then state precisely what breaks when columns are merely correlated: which step of the separability argument dies, and what replaces it (coordinate descent on coupled problems).

Hint Orthonormality makes Xᵀy the OLS estimate coordinatewise and decouples βⱼ’s; correlated columns couple the coordinates through off-diagonal XᵀX entries.
Solution With \(X^\top X = I\): completing the square gives \(\frac{1}{2}\|\beta - b\|^2 + \lambda\|\beta\|_1 + \text{const}\), which is a sum of independent 1-D problems \(\frac{1}{2}(\beta_j - b_j)^2 + \lambda|\beta_j|\). Case |b_j| ≤ λ: minimum at βⱼ = 0 (the V’s corner). Case b_j > λ: optimal βⱼ = b_j − λ; symmetric below. Assemble: \(\hat\beta = S_\lambda(b)\) — shrink everything by λ, drop anything smaller. With correlated columns, XᵀX has off-diagonal mass: βⱼ’s objective depends on the other β’s through them, separability dies, and the solution is characterized by KKT conditions (subgradient of ‖·‖₁ balanced with gradient of RSS) — solved iteratively by coordinate descent, each step a soft threshold of a partial residual estimate. The twins coin-flip lives exactly here: two near-identical columns share one z, and ties break to whichever coordinate descends first.

Q2. Lasso’s degrees of freedom equal the number of selected features (for the Lasso at a given λ). Verify by simulation: compute the covariance-based degrees-of-freedom estimate, \(\text{df} = \frac{1}{\sigma^2}\text{Cov}(\hat\mu_i, y_i)\) over many training draws (use σ known), for a small problem at several λ, and compare to the nonzero count. What does df = |support| buy you conceptually (Cp-style penalties on the lasso path), and why is it surprising (a discontinuous model can have a smooth, integer-valued complexity)?

Hint Zou/Tibshirani/Efron: for the lasso, E[df] = E[#nonzeros] under regularity — testable with the covariance formula.
Solution
The two agree to Monte Carlo noise — the lasso’s degrees of freedom is its support size. Conceptual payoff: you can price lasso models on the Cp scale (RSS + 2σ̂²·|support|) — a bridge between 5.1‘s subset penalties and penalized fitting. The surprise: the fit jumps discontinuously as features enter/leave, yet its expected complexity moves smoothly with λ and equals an integer statistic — one of statistics’ cleaner magic tricks.

6. Complex Questions

C1 (lasso × 5.1 selection instability). Quantify the twin coin-flip at scale: p = 30 features where x₂ = x₁ + small noise and both are truly active with equal coefficients. Run LassoCV selection on 200 bootstrap resamples; report the joint selection frequency of {x₁, x₂} and each individually. Then rerun with elastic net (α_mix = 0.5, 5.4) and compare — the resulting table is the empirical case for the elastic net’s existence.

C2 (lasso × 4.4 bias–variance × 4.1 optimism). Measure lasso’s bias–variance profile across λ with the multi-training-set protocol from 4.4 (300 training sets, n = 60, sparse truth, fixed evaluation grid). Overlay: bias², variance, and the number of selected features per λ. Interpret the three panels jointly — where in λ does variance collapse (sparsity kicks in) relative to where bias starts climbing, and how does that gap explain LassoCV’s typical conservative choice?

7. Summary

  • L1 penalty → exact zeros: shrinkage and selection in one convex fit, solved by coordinate soft-thresholding.
  • Standardize; tune α by CV (LassoCV); α is not portable across n/scales/libraries.
  • Lasso selects twins by coin flip — great for prediction, hazardous for narratives; report selection frequencies.
  • Post-lasso refit (relaxed lasso) trades a little variance for the shrinkage bias back — when the support is stable.
  • At most n features survive in p ≫ n; df of the lasso = its support size.
  • Selection still invalidates naive p-values — the post-selection problem wears a smoother costume.
  • Ridge groups, lasso splits — the compromise that groups and sparsifies: 5.4 Elastic net.
